# AZ Multi

AI-powered social media management and automation dashboard.

## Phase 1 — UI foundation

The first frontend milestone is now in place with:

- Responsive dashboard shell
- Light / Dark / Future theme switcher with saved preference
- Futuristic neon-glass visual mode based on the supplied UI direction
- Dashboard analytics cards and performance visualization
- Connected social account cards for Instagram, Facebook, TikTok and X
- Upcoming posts / scheduler preview
- Unified inbox preview
- AI Content Studio prompt and demo caption generation
- Recent campaigns and top content sections
- Multi-platform Create Post modal
- Sidebar navigation scaffold for Analytics, Scheduler, Inbox, AI Studio, Content, Campaigns, Contacts, Integrations and Settings

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
